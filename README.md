# University Course Management System

A web-based academic workflow system designed to manage university courses, student records, and grading.

## Features
- **Student Dashboard:** Students can log in to view their enrolled courses and semester results (read-only access).
- **Teacher / Admin Dashboard:** Instructors can view course details, assign marks, and update student grades.
- **Role-Based Access Control:** Strict permission separation ensuring students cannot modify any grade records or academic data.
- **CRUD Operations:** Complete create, read, update, and delete functionality for managing student enrollments and course data.

## Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** HTML, CSS, JavaScript
- **Data & Configuration:** JSON, REST API
